Prime Polo recovery build: 8.1-mandatory-profile-gate

Mandatory dashboard gate:
- Authenticated users cannot see or interact with the dashboard until a complete work profile is saved.
- The setup modal cannot be closed or skipped for first-time users.
- Users must select Company, Influencer or Other.
- Required contact and profession fields are validated by both browser and server.
- Influencers must select a platform; all users must select at least one service.
- Only server-confirmed profiles with completed_at unlock the dashboard.
- If profile storage is misconfigured, access stays locked and a setup error with Retry is shown.
- After successful save, the dashboard unlocks automatically.

Required setup:
1. Run supabase/user_work_profiles.sql in Supabase SQL Editor.
2. Configure SUPABASE_URL and SUPABASE_SECRET_KEY in Vercel.
3. Redeploy.
