Prime Polo recovery build: 18.0-admin-website-editor

New /admin Website Editor:

Editable sections:
- Homepage hero: overline, brand signal, three headline lines, kicker, description, CTAs and hero image
- Homepage SEO title and meta description
- Business details: general/support emails, phone, WhatsApp, address, hours, Instagram, LinkedIn and Maps URL
- Founder/about heading, biography and role
- Services: add, edit, reorder, hide, remove and change links
- Creative showcase: add, edit, reorder, remove, image URL and capability link
- FAQ: add, edit, reorder, hide and remove
- Section visibility: Blog, capability results, showcase, working standards, growth audit and EduEx link

Publishing workflow:
- Save Draft
- Preview Draft at /?cms_preview=1
- Publish one section
- Publish all drafts
- Revision history
- Administrator rollback to a prior revision
- Public visitors see only published content
- Staff can draft; only admin can publish or roll back

Media Library:
- Upload JPEG, PNG, WebP or GIF up to 5 MB
- Supabase Storage site-media bucket
- Alternative text and asset history
- Copy public media URL into hero/showcase fields
- Admin-only uploads

Database/API:
- public.site_content
- public.site_content_history
- public.site_media_assets
- /api/site-content
- /api/site-media
- SQL migration: supabase/site_cms.sql

Safety:
- No arbitrary HTML or JavaScript editor
- Structured fields only
- Server-side staff/admin role checks
- Draft/published separation
- Existing built-in content remains as fallback if CMS is unavailable
